# 🎯 Number Guessing Game (Python Console)

A simple and fun console-based Number Guessing Game built with Python. The user tries to guess a randomly generated number between 1 and 100. The game includes difficulty levels that adjust how many attempts the player gets.

## 🕹️ How to Play

1. Run the game.
2. Choose your difficulty level:
   - `easy` → 10 attempts
   - `medium` → 5 attempts
   - `hard` → 3 attempts
3. Try to guess the number!
4. After each guess, the game will tell you if the correct number is higher or lower.
5. If you run out of attempts, the correct number and a final hint will be revealed.

## 💡 Features
- Difficulty selection (easy, medium, hard)
- Random number generation
- Input validation for non-numeric guesses
- Feedback after each guess (higher/lower)
- Final message if the user runs out of attempts
